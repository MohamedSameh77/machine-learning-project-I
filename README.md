# machine-learning-project-I
An end-to-end machine learning project using Python, Scikit-learn, and Jupyter Notebook

Open this folder in VS Code, then select `.venv\Scripts\python.exe` through
**Python: Select Interpreter**. In `bike_sharing_demand.ipynb`, use
**Select Kernel → Python Environments** to choose the same environment.
Restart the notebook kernel and run all cells. The first cell prints the
interpreter path and package versions; the next cell loads the CSV files from `data/`.

To set up a new environment from PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
